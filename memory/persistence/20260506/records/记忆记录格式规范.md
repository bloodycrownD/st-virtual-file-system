# 记忆记录格式规范（Memory Records）

## 日期

2026-05-06

## 背景

项目需要把“记忆/结论/决策”以统一格式沉淀，区分持久与临时，并通过索引可追溯管理，方便后续持续追加与检索。

## 结论 / 事实

- 记忆记录按项目约定落在 `memory/` 目录：
  - 持久：`memory/persistence/<yyyyMMdd>/index.md` 与 `memory/persistence/<yyyyMMdd>/records/...`
  - 临时：`memory/tmp/index.md` 与 `memory/tmp/records/...`
- **每新增一条记录，必须同步更新对应 `index.md`**。
- 详细字段规范与可复制模板统一维护在：
  - `docs/memory-records.md`

## 影响 / 下一步

- 新增记忆时优先按 `SKILL.md` 模板写 Markdown 记录文件，并补索引。
- 如果后续需要程序化处理（去重/合并/导入导出），以 `docs/memory-records.md` 的结构化字段为准扩展实现。
