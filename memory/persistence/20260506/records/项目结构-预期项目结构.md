# 预期项目结构（目标蓝图）

## 日期

2026-05-06（迁移整理）

## 背景

`docs/plan/预期项目结构.md` 描述了一份“目标结构蓝图”，用于指导后续模块拆分与目录归类。

## 结论 / 事实

- 该文档是“目标态”目录树，用于指导演进方向（components/features/core/stores/utils/types/views 等分层）。
- 与当前仓库实际结构可能存在偏差（属于“计划/设计”而非事实快照）。

## 影响 / 下一步

- 未来若继续重构，建议把此蓝图作为对照标准：
  - 新增模块优先放入对应层级
  - 逐步减少“demo/临时代码”对主结构的侵入
- 每次接近达成一个阶段目标后，补一条“已落地变化点”的持久记忆记录，避免蓝图失真。
