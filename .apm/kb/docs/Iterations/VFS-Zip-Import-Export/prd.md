# VFS ZIP 导入/导出 PRD

## 背景

当前虚拟文件系统（VFS）仅支持在 SillyTavern 内编辑，以及通过「覆盖」将扩展模板写入当前 chat。用户无法在 chat 之间、或与外部工具之间批量迁移整棵 VFS 文件树。需要在文件列表顶栏「覆盖」按钮旁增加**导出**与**导入**，以 ZIP 为载体完成整库备份与恢复。

## 目标（含成功指标）

- 用户可在 **chat** 与 **扩展模板** 两种作用域下，一键导出当前作用域的**完整 VFS 文件树**为 ZIP，并在浏览器中自动下载。
- 用户可从 ZIP **全量替换**当前作用域的 VFS（导入前二次确认），副作用与「覆盖」一致（清空执行日志与检查点/版本历史）。
- **成功指标**：
  - 导出后 ZIP 内路径与 VFS 虚拟路径一致（保留目录层级），可被常见解压软件打开。
  - 导入合法 ZIP 后，当前作用域 VFS 节点数与 ZIP 内文件数一致（目录节点按树结构还原）。
  - 导入非法/损坏 ZIP 时，VFS 保持导入前状态，并向用户展示明确错误提示。
  - chat 与模板两种界面均可见导出/导入入口（与「覆盖」同区域；模板界面无「覆盖」时仍显示导出/导入）。

## 用户与场景

| 用户 | 场景 |
|------|------|
| 角色卡/剧情作者 | 备份当前 chat 的全部设定与笔记文件，换设备或重装后恢复 |
| 扩展维护者 | 在模板编辑界面导出模板 VFS，在另一环境导入以同步默认目录结构 |
| 多 chat 用户 | 将 chat A 的 VFS 导出后导入 chat B（全量替换 B 的 VFS） |

## 范围

### 包含范围

1. **UI**：在文件管理列表顶栏、`覆盖` 按钮旁新增「导出」「导入」两个按钮（图标按钮，与现有顶栏风格一致）。
2. **作用域**：`scope=chat` 与 `scope=template` 均提供导出/导入；操作对象分别为当前 chat 的 `chatVfsSnapshot` 与扩展的 `extensionTemplateVfsSnapshot`。
3. **导出**：
   - 遍历当前作用域 VFS 的**全部文件节点**（扩展内均为文本内容），按虚拟路径写入 ZIP（路径以 `/` 为根，ZIP 内使用相对路径，如 `notes/foo.md`）。
   - 不包含工作树配置、目录规则、检查点、执行日志等元数据。
   - 完成后触发浏览器下载，文件名自动生成（如 `vfs-export-<时间戳>.zip`）。
4. **导入**：
   - 通过系统文件选择器选择 `.zip`。
   - 导入前弹出确认对话框，明确说明将**清空当前作用域 VFS 后写入 ZIP 内容**，且**执行日志与检查点/版本历史将一并清空**（与「覆盖」一致）。
   - 用户确认后：清空当前作用域 VFS → 按 ZIP 内容重建文件树 → 清空该作用域相关日志与检查点 → 刷新文件列表 UI。
   - ZIP 内仅处理可作为 VFS 文件写入的条目（文本文件；非法路径或无法解析的条目跳过或整体失败策略在实现阶段于 SPEC 中二选一，默认：**任一路径非法则整次导入失败并回滚**）。
5. **反馈**：进行中显示加载/禁用态；成功/失败使用与扩展一致的 toast 提示。

### 不包含范围

- 工作树、目录规则、宏配置等元数据的导入/导出。
- 部分目录/勾选文件的导出或导入。
- 合并式导入（跳过已存在、仅覆盖同名等）；本需求仅**全量替换**。
- 云端同步、自动定时备份。
- 虚拟工具（`virtual-tool-call` / Function Calling）侧的 ZIP 能力。
- 导入/导出进度条、ZIP 内加密、分卷压缩。

## 核心需求

1. 在 `VfsMainScreen` 文件列表顶栏「覆盖」旁增加「导出」「导入」按钮；chat 与 template 作用域均可见。
2. **导出**：将当前作用域完整 VFS 文件树打包为 ZIP 并自动下载；ZIP 仅含文件内容与目录结构。
3. **导入**：选择 ZIP → 二次确认（含清空 VFS + 日志/检查点说明）→ 全量替换当前作用域 VFS，副作用与「覆盖」一致。
4. 导入失败时不得破坏导入前已有 VFS（事务性：失败则保持原状）。
5. 操作完成后刷新文件管理器列表；若当前打开的文件已不存在，回到列表视图或给出合理提示。
6. 对空 VFS、空 ZIP、损坏 ZIP、路径越界（如 `../`）等边界情况给出可理解的用户提示。

## 验收标准

### 导出

- **Given** 当前 chat 作用域存在至少 1 个文件节点，**When** 用户点击「导出」，**Then** 浏览器下载一个 `.zip`，解压后文件路径与 VFS 虚拟路径一致（不含 leading `/` 的 ZIP 内路径），文件内容与 VFS 中一致。
- **Given** 当前作用域 VFS 为空，**When** 用户点击「导出」，**Then** 仍下载 ZIP（可为仅含空目录结构或空 archive，行为在 SPEC 中固定一种）或提示「无可导出文件」——实现前在 SPEC 选定其一；验收以 SPEC 为准。
- **Given** `scope=template`，**When** 用户导出，**Then** 下载内容为模板 VFS，而非当前 chat VFS。

### 导入

- **Given** 用户选择合法 ZIP 且在确认框点击确认，**When** 导入完成，**Then** 当前作用域 VFS 与 ZIP 内文件树一致；该作用域执行日志与检查点/版本历史已清空；文件列表已刷新。
- **Given** 用户在确认框点击取消，**When** 关闭对话框，**Then** VFS、日志、检查点均无变化。
- **Given** ZIP 损坏或含非法路径，**When** 用户确认导入，**Then** 导入失败并 toast 错误信息，且导入前 VFS 内容保持不变。
- **Given** `scope=template`，**When** 用户成功导入，**Then** 仅更新 `extensionTemplateVfsSnapshot`，不影响任意 chat 的 VFS。

### UI 与一致性

- **Given** chat 文件列表顶栏，**When** 查看按钮区，**Then** 「覆盖」「导出」「导入」相邻展示（模板作用域无「覆盖」时，「导出」「导入」仍展示）。
- **Given** 导入/导出进行中，**Then** 对应按钮禁用或显示进行中状态，避免重复触发。

### 非目标回归

- **Given** 用户仅使用原有「覆盖」功能，**When** 未使用导入/导出，**Then** 「覆盖」行为与现网一致，无变化。
