# VFS 预览仅 Markdown 渲染 PRD

## 背景

当前扩展在**编辑器预览**、**只读阅读**、**目录幻灯片**等路径中，对 `.txt` 等非 Markdown 文件同样走 `marked` 渲染。纯文本中的 `#`、`*`、链接语法等会被误解析，阅读体验与「源码」不一致；用户期望非 Markdown 文件**不做 Markdown 渲染**，以原文形式展示。

## 目标（含成功指标）

- **体验目标**：仅 `.md` 文件享受 Markdown 排版；其它文本扩展名在各类阅读界面中以**与源码一致的纯文本**展示（可保留预览按钮，切换前后视觉一致或预览区为等宽原文）。
- **成功指标**：
  - 打开 `.txt`（或 `.markdown` 等非 `.md` 文本）时，预览/阅读区不出现标题、列表等 Markdown 误渲染。
  - `.md` 文件预览/阅读行为与现网一致（含 YAML 前置区展示策略，若已实现）。
  - 编辑器「预览渲染 / 查看源码」按钮**仍保留**于所有文本文件顶栏（不因扩展名隐藏）。

## 用户与场景

| 用户 | 场景 |
|------|------|
| 写设定/脚本的作者 | 用 `.txt` 存纯文本，打开后不应把 `# 标题` 渲染成 H1 |
| 阅读 `.md` 故事卡的用户 | 继续需要渲染后的排版阅读 |
| 目录幻灯片浏览 | 混有 `.md` 与 `.txt` 时，各文件按类型分别渲染或原文展示 |

## 范围

### 包含范围

1. **判定规则**：扩展名**仅** `.md`（大小写不敏感，如 `.MD`）视为 Markdown；**不含** `.markdown` 及其它扩展名。
2. **编辑器模式**（`editorPreviewMode` / 顶栏预览切换）：
   - `.md`：预览区 Markdown 渲染；源码区为 textarea（现状）。
   - 非 `.md`：预览区展示**与源码相同的纯文本**（不调用 Markdown 解析）；切换预览/源码时内容一致，仅布局/样式可不同（如预览用 `pre-wrap` 只读区）。
3. **只读阅读模式**（`mode === 'reader'`）：同上，非 `.md` 不 Markdown 渲染。
4. **目录幻灯片**（`slideshow`）：当前页文件非 `.md` 时，幻灯片内容区纯文本展示，不 Markdown 渲染。
5. **预览按钮**：所有文本文件均保留；非 `.md` 点击预览不产生 Markdown 副作用。

### 不包含范围

- 修改工作树宏 `{{VIRTUAL_WORK_TREE}}` 的纳入/渲染规则（仍可按现有 `isMarkdownFile` 等逻辑，本需求仅 UI 阅读路径）。
- 新增「按内容嗅探是否为 Markdown」；**仅按扩展名**。
- 修改虚拟工具、ZIP 导入导出、Function Calling。
- 为非 `.md` 增加语法高亮、PDF 等其它查看器。

## 核心需求

1. 提供统一的「当前文件是否 Markdown 预览」判定（路径 → 扩展名 `.md`），供 `VfsMainScreen`、`EditorScreen`、`ReaderScreen`（或等价展示组件）共用。
2. `.md`：继续走现有 `renderSafeMarkdownDocument` / `ReaderScreen` 渲染链路。
3. 非 `.md`：阅读/预览路径使用**纯文本展示**（HTML 转义 + 保留换行），禁止对正文调用 `marked`。
4. 切换打开的文件时，若从 `.md` 切到非 `.md`，应退出「误用 Markdown 渲染」状态（非 `.md` 下 `editorPreviewMode` 可为 true，但展示仍为原文）。
5. 幻灯片、全屏阅读等共用内容区行为与上述规则一致。

## 验收标准

### Markdown（`.md`）

- **Given** 文件路径以 `.md` 结尾（如 `/story/ch1.md`），**When** 以只读或编辑器预览打开，**Then** 正文按 Markdown 渲染（标题、列表等可见），与当前 `.md` 行为一致。

### 非 Markdown（如 `.txt`、`.markdown`）

- **Given** 文件为 `/notes/readme.txt` 且内容含 `# 不是标题`，**When** 只读打开，**Then** 页面显示字符 `# 不是标题`，**不**出现 HTML `<h1>` 级标题样式。
- **Given** 同上 `.txt`，**When** 编辑器内点击「预览渲染」，**Then** 预览区仍为原文（与 textarea 内容一致），**不**出现 Markdown 渲染副作用。
- **Given** 文件为 `/x/readme.markdown`，**When** 阅读或预览，**Then** 按**纯文本**展示（本需求明确 `.markdown` 不视为 Markdown）。

### 幻灯片

- **Given** 目录幻灯片含 `a.md` 与 `b.txt`，**When** 翻到 `b.txt` 页，**Then** 该页纯文本展示；翻到 `a.md` 页，**Then** Markdown 渲染。

### UI 一致性

- **Given** 任意文本文件，**When** 查看顶栏/工具栏，**Then** 「预览渲染 / 查看源码」按钮仍存在且可点击（非 `.md` 不因扩展名隐藏）。

### 回归

- **Given** 仅使用 `.md` 文件，**When** 阅读与预览，**Then** 与改动前 `.md` 体验无可见退化。
