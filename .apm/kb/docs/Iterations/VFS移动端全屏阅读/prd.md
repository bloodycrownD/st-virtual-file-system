# VFS 移动端全屏阅读 PRD

## 背景

在 SillyTavern 扩展弹窗（`#st-vfs-popup` / `#st-vfs-popup-app`）内，移动端视口高度与宽度受限，文件预览与编辑器（含预览渲染）的可读区域过小，影响长时间阅读与校对。宿主弹窗尺寸并非本扩展单独可控，需要在扩展内提供 **浏览器原生全屏** 能力，以便占满设备屏幕进行沉浸式阅读。

## 目标（含成功指标）

- **体验目标**：用户在移动端进入文件预览栈后，可一键进入全屏，阅读区显著大于弹窗内嵌区域；退出路径清晰。
- **成功指标（可验证）**：
  - 支持全屏的环境下，用户可在 **3 步以内**（进入预览栈 → 点全屏 → 可选点返回）完成「全屏阅读 → 退出全屏」闭环。
  - 全屏态下 **Pre/Next** 与当前非全屏逻辑 **一致**（单文件、目录幻灯片等边界与现实现象对齐，不引入新的分页语义）。

## 用户与场景

- **用户**：在手机或小窗宽下使用 VFS 阅读 Markdown、带 YAML 的故事稿，或在编辑器中切换预览校对的用户。
- **场景**：弹窗内正文区域过小；用户希望全屏占满屏幕阅读，并在全屏内仍能翻页（目录多文件时）或返回弹窗内视图。

## 范围

### 包含范围

- 在 **文件预览栈**（非文件列表主界面）提供 **全屏** 入口：含 **阅读**、**幻灯片**、**编辑器**（含 **源码编辑** 与 **预览渲染**）等当前已进入「单文件/多文件预览」壳层的模式。
- 使用 **浏览器 Fullscreen API**（`requestFullscreen` 等）使 **仅预览内容区** 对应的 DOM 根节点进入全屏（**已确认**：不是整块 `#st-vfs-popup-app`），以便全屏画面内主要是阅读/编辑区与全屏工具条，降低宿主弹窗 chrome 干扰；具体节点选择见后续 spec。
- **全屏态顶部/悬浮工具条**（或等价可发现 UI）至少包含：
  - **返回**：退出全屏并恢复进入全屏前的弹窗内状态（不丢失未保存编辑的责任边界与现有一致：若需拦截应与现有未保存提示对齐）。
  - **Pre / Next**：行为、禁用条件与 **当前非全屏** 下现有实现 **一致**（用户明确要求「参考现在的实现」）。
  - **编辑器场景**（处于可编辑文件且工具条已存在对应能力时）：增加与现有一致的 **预览/源码切换**、**保存**（含保存中态），以便全屏内继续编辑与保存，而不必先退出全屏。
- **阅读/幻灯片**（非编辑器源码工作流）：全屏工具条 **不强行要求** 出现保存按钮（与现能力一致即可）。

### 不包含范围

- 改变 SillyTavern 宿主弹窗默认尺寸或全局布局。
- 非 Fullscreen API 的「伪全屏」作为首版交付（若需无 API 环境的降级，可作为后续迭代，本 PRD 不强制）。
- 全屏下重做文件树、工作树、历史等 **列表级** 功能入口（全屏聚焦阅读/编辑条带）。

## 核心需求（3–7 条）

1. 在文件预览栈内提供 **全屏** 控件，触发后调用 Fullscreen API，使 **仅预览内容区** 的 DOM 根节点进入全屏，预览/编辑主体占满该全屏区域。
2. 全屏态提供 **返回**，用于退出全屏；退出后 UI 状态与进入全屏前一致（含当前文件、预览/源码开关、滚动位置 **尽力** 保持，滚动为尽力项可在实现 spec 中约定）。
3. 全屏态提供 **Pre / Next**，逻辑与禁用规则与 **现实现有预览顶栏** 一致。
4. 当用户处于 **编辑器** 相关模式时，全屏工具条需包含 **预览/源码切换** 与 **保存**（与当前预览顶栏能力对齐，含不可用态）。
5. 在 Fullscreen 不可用或用户拒绝权限时，有 **可感知反馈**（如 toastr/禁用态说明），不静默失败。

## 验收标准

1. **Given** 设备与浏览器支持 Fullscreen API **When** 用户在文件预览栈点击全屏 **Then** **仅预览内容区** 进入全屏且该区域占满屏幕可用空间（整块扩展壳 `#st-vfs-popup-app` 不要求进入全屏）。
2. **Given** 已处于全屏 **When** 用户点击返回 **Then** 退出全屏并回到弹窗内同一预览上下文（同文件、同模式优先）。
3. **Given** 单文件打开与目录幻灯片两种上下文 **When** 在全屏与非全屏分别操作 Pre/Next **Then** 可点击性与翻页结果一致（与当前实现对照，无回归）。
4. **Given** 编辑器模式（含源码与预览）**When** 进入全屏 **Then** 工具条可见预览/源码切换与保存，且保存流程与现有一致（含进行中禁用/提示）。
5. **Given** 阅读或幻灯片（非编辑器）**When** 进入全屏 **Then** 不出现「仅编辑器才有意义」的保存按钮误导（可不展示保存）。
6. **Given** Fullscreen 请求失败或遭拒 **When** 用户点击全屏 **Then** 出现明确错误/提示，且不破坏当前非全屏布局。
