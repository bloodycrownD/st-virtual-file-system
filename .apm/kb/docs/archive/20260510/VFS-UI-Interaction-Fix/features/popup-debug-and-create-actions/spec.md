# popup-debug-and-create-actions 需求说明

## 背景

在 `VFS UI/交互修复` 主需求实现过程中，出现了两类“看起来无响应”的情况：

- 弹窗已挂载 Vue，但用户点击 `Up/更多操作` 仍感觉无响应。
- 文件列表为空、未选中实体时，“更多操作”会处于禁用状态且缺乏解释；同时 UI 缺少“新建文件/目录”入口，导致列表长期为空。

另外，为了定位“是否点击事件被宿主吞掉/覆盖层遮挡”，需要一个仅在开发模式启用的可观测探针（Test 按钮 + click probe），用于快速判断事件是否到达弹窗。

## 目标

- 在弹窗文件管理器中提供 **新建目录/新建文件** 的入口，使用户可以在空目录下开始操作，避免“永远无可选项”的状态。
- 对“更多操作”禁用状态提供 **可见原因提示**，降低误判为 bug 的概率。
- 弹窗挂载链路增强：避免 `innerHTML` 在宿主环境被重写导致 `#st-vfs-popup-app` 丢失，提供可关闭的弹窗 chrome。
- 提供仅 DEV 启用的“点击可观测”探针，帮助快速定位宿主事件吞噬/覆盖层问题。

## 范围

### 包含范围

- 文件管理器顶部增加：
  - `新建目录`（prompt 输入目录名）
  - `新建文件`（prompt 输入文件名）
- “更多操作”在禁用状态时提供 `title` 提示文案（需选择文件/目录后才可用）。
- 弹窗容器使用 DOM 节点方式组装（不依赖 `innerHTML`），并提供显式关闭按钮（`×`）。
- 仅在 `import.meta.env.DEV` 时启用：
  - 弹窗标题栏 `Test` 按钮（点击输出日志/视觉反馈）
  - click probe（dialog + document capture）
- 保留并增强弹窗 `pointer-events/z-index` 的兜底，仅作用域于 `#st-vfs-popup`。

### 不包含范围

- 不引入更复杂的新建 UI（例如内联输入框/自定义表单）；本次采用浏览器 `prompt`。
- 不改动虚拟工具协议与 VFS 域模型能力。

## 功能需求

### FR-1 新建目录/新建文件入口

- 在文件管理器面板顶部（与 Up 同一行）提供两个按钮：`新建目录`、`新建文件`。
- 点击后弹出 prompt 输入名称：
  - 目录：调用 VFS `mkdir` 创建目录
  - 文件：创建空文件（必要时创建父目录）
- 创建成功后：
  - 列表应出现新条目
  - 选中路径更新到新建项（便于后续更多操作）

### FR-2 “更多操作”禁用原因提示

- 当没有选中实体导致“更多操作”禁用时，summary 上应有 `title`：
  - `先选择一个文件/目录，然后使用“更多操作”`

### FR-3 弹窗挂载加固 + 关闭按钮

- 弹窗 DOM 结构通过 `createElement/append` 组装，必须包含：
  - `header`（标题 + 关闭按钮）
  - `div#st-vfs-popup-app`（Vue mount root）
- 关闭按钮点击应触发弹窗关闭/卸载逻辑。

### FR-4 DEV 探针（仅开发模式）

- DEV 模式在弹窗标题栏显示 `Test` 按钮：
  - 点击时输出日志（`console.log`）
  - 同时提供最小视觉反馈（按钮文本 `Test` ↔ `Test✓`）
- DEV 模式启用 click probe：
  - dialog capture probe：打印点击落点的 `closest` 信息
  - document capture probe：当 composedPath 包含弹窗时打印事件摘要

### FR-5 交互兜底样式（限弹窗作用域）

- 对 `#st-vfs-popup` 范围内强制 `pointer-events: auto !important`，避免宿主样式禁用交互。
- 对 backdrop 禁止 pointer events，避免遮罩误吃点击。

## 非功能需求

- **可追踪性**：新增行为必须能从日志/DOM 结构判断是否生效（尤其 DEV 探针）。
- **最小污染**：所有 CSS/DOM 变更都必须限定在 VFS 自己的弹窗与组件作用域内，避免影响宿主。
- **可回滚**：DEV 探针不得影响生产行为；生产构建不应包含 Test 按钮与探针监听。

## 验收标准

- **AC-1 新建入口可用**：在空目录下点击 `新建目录`/`新建文件`，输入名称后列表出现对应条目。
- **AC-2 更多操作提示**：未选中实体时，“更多操作” hover 可看到禁用原因；选中后可展开并执行动作。
- **AC-3 弹窗可关闭**：弹窗存在可见 `×`，点击可关闭且不会残留不可见遮罩。
- **AC-4 DEV 探针可观测**：DEV 下点击 `Test` 能看到 `console.log` 且按钮文本切换；点击其他按钮能输出 probe 日志。

## 风险与待确认项

- 宿主主题/插件可能有更强的事件拦截逻辑；若仍出现“无日志”，需要进一步从宿主层排查（例如全局捕获阻断、透明 overlay）。
