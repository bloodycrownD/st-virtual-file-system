# icon-only-toolbar-header 需求说明

## 背景

当前文件管理面板相关区域在完成图标化后，仍存在“文件管理器”文字标签，产生语义重复与视觉冗余：

- 文件管理面板头部与顶部 tab 区域出现“文字 + 图标”混合表达，信息密度不合理。
- 与“尽量 icon 化、减少文字”的迭代方向不一致。
- 占用头部空间，影响整体紧凑性与平衡感。

## 目标

- 保留文件管理面板头部图标入口（panel icon）。
- 移除顶部 files tab 的可见文字标签（允许 icon-only tab）。
- 保持工具栏/标签语义不重复，维持 icon-only 风格一致。
- 在不破坏布局平衡的前提下，保持 desktop/mobile 一致体验。

## 范围

### 包含范围

- 组件范围：
  - `VfsFileManagerPanel` 头部中“面板标题位”（panel-title）相关结构与样式。
  - 文件管理 files tab（顶部 tab 文案）相关结构与样式。
- 调整内容：
  - 移除“文件管理器”可见文字。
  - 保留面板头部图标入口，不新增额外文字入口。
  - 移除 files tab 可见文字，仅保留图标可见。
  - 校正头部布局，使剩余按钮组对齐自然、视觉平衡。

### 不包含范围

- 不调整设置面板中的文案按钮。
- 不改变 Up / 更多操作 的交互语义，仅允许必要的布局联动。
- 不新增新的工具栏按钮或 tab 类型，仅做现有元素文案/可见性调整。

## 功能需求

### FR-1 去除可见标题文字（保留图标）

- 文件管理面板头部默认状态下，不出现“文件管理器”可见文字。
- 头部图标入口必须保留可见，不得被一并移除。
- 标题位对应文字 DOM 可删除或不可见，但不得留下明显空白占位。

### FR-2 Files Tab icon-only

- files tab 默认状态下，不显示“文件管理器”可见文字标签。
- files tab 保留图标可见与可点击，不改变既有 tab 交互语义。

### FR-3 语义去重

- 面板头部不再出现与现有图标入口重复的“同义标识”。
- 工具栏保留必要操作入口（如 Up、更多操作），不新增重复入口。
- tab 区域同样不再出现与图标重复的可见同义文字。

### FR-4 布局平衡

- 移除文字后，头部按钮组与 tab 组仍保持一行对齐与间距一致。
- 在桌面与移动布局中，均不得出现明显错位、拥挤或异常留白。

## 非功能需求

- **一致性**：保持与当前 icon-only 工具栏视觉基线一致（尺寸、边框、间距）。
- **可维护性**：优先删除冗余节点，避免通过复杂 CSS 隐藏保留无用结构。
- **兼容性**：变更应限定在 VFS 面板作用域，避免影响宿主页面其它按钮。

## 验收标准

- **AC-1 头部保留图标且无文字**：默认状态下，面板头部图标可见且不显示“文件管理器”文字。
- **AC-2 files tab icon-only**：files tab 不显示“文件管理器”文字，图标可见且可交互。
- **AC-3 无重复语义**：头部与 tab 仅保留必要入口，不再出现文字+图标同义重复。
- **AC-4 布局平衡**：头部与 tab 视觉紧凑且平衡，无异常空白或错位。
- **AC-5 双端一致**：desktop/mobile 下均满足以上标准。

## 风险与待确认项

- 去除可见文字后，新用户可能更依赖图标语义；需保持头部与 tab 的 `title/aria-label` 完整。
