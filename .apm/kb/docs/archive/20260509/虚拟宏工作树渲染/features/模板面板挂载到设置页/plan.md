# 变更方案：模板面板挂载到设置页

## 目标

实现模板管理的独立入口与最小能力集：

- 设置页可打开模板文件系统弹窗。
- 模板弹窗只保留 Tab1 能力（无日志、无版本管理）。
- 新建 chat 自动按模板初始化。
- chat 面板支持“模板覆盖当前目录”。

## 设计原则

- **单向复制**：模板仅作为来源，应用到 chat 时不反向写回模板。
- **能力裁剪**：模板模式禁用提交记录/日志链路，避免引入无效复杂度。
- **安全交互**：覆盖前必须确认，覆盖后统一刷新相关视图。
- **兼容主需求**：不改宏输出协议与核心 VFS 领域语义。

## 实施步骤

1. **设置页挂载入口**
   - 在 `src/App.vue` 增加“模板管理”入口按钮。
   - 绑定打开模板弹窗的状态与事件。

2. **模板弹窗模式化**
   - 复用现有文件系统 UI（Tab1）并引入 `templateMode`（或等效模式标识）。
   - 在模板模式下隐藏/禁用 Tab2、Tab3 与相关动作入口。
   - 校验模板模式不注册日志/版本管理相关 hooks。

3. **新建 chat 初始化接入模板**
   - 在 chat 创建流程中加入“读取 ext 模板 -> 深拷贝 -> 初始化 chat VFS”。
   - 模板不存在时走默认初始化，保证 chat 快照合法。

4. **chat 覆盖动作**
   - 在 chat 面板加入“模板覆盖当前目录”按钮。
   - 点击后弹出确认框（不可恢复提示）。
   - 确认后执行模板到 chat 的覆盖，并统一刷新文件树/阅读与宏依赖状态。
   - 覆盖成功后清空 chat 的日志与版本管理状态（按“重新初始化”处理）。

5. **错误处理**
   - 覆盖失败与初始化失败统一映射错误码并 `toastr.error` 展示。
   - 失败时不留下半更新状态（以原子替换或完整回滚为目标）。

## 手工验证

1. 进入设置页，点击“模板管理”，弹窗正常打开。
2. 模板弹窗内可执行 Tab1 核心操作（新建/编辑/删除等）。
3. 模板弹窗内确认无日志/版本管理入口。
4. 新建 chat 后，文件树与模板内容一致。
5. 在 chat 点击“模板覆盖当前目录”：
   - 未确认时不覆盖。
   - 确认后完成覆盖并刷新 UI。
   - 覆盖后日志面板与版本历史为空。

## 回滚策略

- 若上线后模板模式影响 chat 主流程，可先保留设置页入口但关闭“覆盖”动作开关。
- 紧急情况下可回退到“仅新建 chat 初始化模板”，暂时移除手动覆盖入口。
