# VFS-Style-Optimization 需求说明

## 背景

当前 VFS 文件管理相关面板在阅读体验上存在几个问题：缺少时间信息、标题层级不明显、正文区域缺少边框隔离，以及长文本换行后右侧出现异常留白。以上问题影响可读性、信息密度与视觉一致性。

## 目标

- 为文件内容展示补充创建时间与更新时间，提升信息完整度。
- 强化标题视觉层级（加粗 + 稍大字号），提升信息定位效率。
- 为正文展示区域增加符合当前主题风格的边框隔离。
- 修复文本换行与右侧空白问题，优化阅读排版体验。
- 在改动中平衡可读性、信息密度与视觉一致性。

## 范围

### 包含范围

- VFS 文件管理相关所有面板中的文件内容展示区。
- 与文件内容展示直接相关的标题、元信息（时间）、正文容器样式。
- 文本换行与排版策略调整（包含右侧异常空白修复）。

### 不包含范围

- 非 VFS 文件管理相关页面。
- 文件内容编辑能力、保存逻辑或数据结构改造。
- 主题系统全局配色方案重构。

## 功能需求

1. 在文件内容展示区域新增“创建时间 / 更新时间”信息。
2. 时间格式使用本地化短日期时间格式（示例：`2026-05-10 22:37`，具体以运行环境 locale 输出为准）。
3. 时间信息以小号字体展示，位置优先放置在内容区域右下角（若布局冲突，可采用等价视觉效果方案，但需保持“次级信息”层级）。
4. 文件标题改为加粗字体，并将字号相对现状上调一个可感知档位。
5. 正文展示区域新增边框隔离，风格需与当前 VFS 视觉体系一致（不破坏现有主题观感）。
6. 文本展示采用类 Markdown 阅读排版（提升段落/行高可读性）。
7. 修复长文本换行后右侧异常空白问题，确保内容区域宽度利用合理，不出现明显无效留白。

## 非功能需求

- 样式改动应保持跨主流桌面分辨率下的稳定显示。
- 不引入明显的交互卡顿或布局抖动。
- 兼容现有主题变量，不出现与全局主题冲突的突兀样式。
- 保持现有主要交互路径不变（打开、切换文件、返回等）。

## 验收标准

1. 在 VFS 文件管理相关所有面板中，文件内容展示区均可看到创建时间与更新时间（本地化短日期格式），且视觉为次级信息层级。
2. 标题在同一面板内视觉上明显高于正文（加粗且字号更大）。
3. 正文区域具备清晰但不过度突兀的边框隔离，整体风格与现有界面一致。
4. 长文本与超长段落显示时，无右侧大面积异常空白；阅读区域宽度利用正常。
5. 文本排版符合“类 Markdown 阅读体验”，可读性相比当前版本有提升。
6. 上述改动不影响现有文件浏览与切换流程。

## 风险与待确认项

- “本地化短日期格式”在不同浏览器/系统 locale 下展示细节可能不同，需要确认是否允许这种差异。
- “右下角”时间信息在极小高度窗口中可能与滚动条或底部控件发生视觉冲突，需在实现阶段确定降级布局。
- “类 Markdown 排版”需明确最小实现集合（如行高、段间距、长词换行策略），避免范围蔓延。
