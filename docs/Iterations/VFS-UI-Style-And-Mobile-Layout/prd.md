# VFS 样式与移动端排版 PRD

## 背景

当前 VFS 在窄视口（尤其移动端）下，长文件名与横向排布的工具区容易把内容撑出视口宽度，出现横向滚动条；编辑器页标题与操作按钮的叠放方式在窄屏下可读性与可达性一般。与此同时，SillyTavern 扩展设置面板中的 VFS 相关控件样式与弹窗内深色主题存在不一致风险，用户希望整体观感统一。

## 目标（含成功指标）

- **视觉一致性**：VFS 弹窗与扩展设置面板中的 VFS 相关区域，在配色、字色、按钮与输入框边框/圆角层级上，与当前产品内“深色底 + 浅色字 + 细边框控件”的风格保持一致（以现有可用界面为参照，而非引入全新设计语言）。
- **横向溢出可控**：在常见手机宽度与桌面窄窗口下，VFS 弹窗内不应因文本或控件排布产生**可感知的横向滚动**（允许浏览器极少量测量误差，但不出现明显横向滚动条作为主交互路径）。
- **编辑器窄屏信息架构清晰**：标题、主要操作按钮、Tab 与回滚区域的阅读顺序稳定，关键操作可点按区域不被挤出视口。

**成功指标（可判定）**

- 在至少两种窄视口宽度下（例如 390px 与 480px 级别）人工验收：VFS 弹窗内无稳定复现的横向滚动条；长文件名以省略号呈现且仍可辨识（通过完整路径的辅助展示方式可选，但不强制）。
- 编辑器页：标题独占一行；主要按钮组独占一行；Tab 与回滚区域允许折行到两行，但**整体左对齐**且不依赖横向滚动完成操作。

## 用户与场景

- **移动端用户**：小屏浏览文件列表、打开长文件名文件、在编辑器中查看/保存/回滚。
- **桌面窄窗口用户**：分屏、侧栏较宽导致 VFS 弹窗可用宽度变窄。
- **配置用户**：在扩展设置中开关 VFS、调整保留条数、进入模板管理；希望设置区与弹窗风格不割裂。

## 范围

### 包含范围

- **VFS 弹窗内全部 Tab 及其子区域**：文件管理、执行与回滚、工作树、编辑器（含检查点选择与回滚工具条等相关控件）。
- **SillyTavern 扩展设置面板中与本扩展相关的 VFS 配置区块**：与弹窗风格对齐（含文案与控件视觉层级的一致性；若存在与“检查点/保留条数”语义相关的标签，应与当前产品术语一致）。
- **超长文件名省略展示**：凡在弹窗内以“文件名/路径片段”作为列表项或标题展示且可能撑宽布局的区域，均应采用可截断策略（`ellipsis` 或等价方案），并配合布局约束避免父级出现横向溢出。

### 不包含范围

- 不改变 VFS 核心业务逻辑（检查点、回滚语义、持久化结构等）。
- 不承诺覆盖 SillyTavern 宿主全局主题系统；仅保证本扩展提供的 DOM 区域在现有宿主皮肤下尽量一致、且不引入新的横向滚动问题。
- 不在本 PRD 中规定具体 CSS 变量命名、组件拆分方案与像素级设计稿（留给实现阶段 SPEC）。

## 核心需求（3–7 条）

1. **统一风格**：扩展设置面板中的 VFS 相关控件与 VFS 弹窗在深色背景、浅色正文、输入框与按钮边框/圆角节奏上保持一致（以当前弹窗/设置区可用样式为参照进行对齐）。
2. **禁止“文件名撑爆横向布局”**：文件列表等行内布局在窄屏下应优先压缩中间文本区域，使行尾控件不被挤出；长文件名使用省略号截断。
3. **弹窗内避免横向滚动**：通过 `min-width:0`、弹性子项收缩、必要时换行与截断组合，确保主要浏览路径不出现横向滚动条。
4. **编辑器移动端排版**：
   - 标题单独一行；
   - 主要操作按钮单独一行；
   - Tab 与回滚区域允许两行折行，但必须左对齐（不依赖居中分布来“硬塞”一行）。
5. **可访问性不降级**：截断后仍应保留合理的可聚焦控件与可见命中区域（例如返回、保存、回滚），不因截断导致不可操作。

## 验收标准

### A. 横向滚动与截断

- **Given** 视口宽度为 390px（或等价移动设备模拟宽度）  
  **When** 用户在文件管理 Tab 浏览包含极长文件名的目录  
  **Then** 弹窗内容区不出现用于浏览主列表的横向滚动条；长文件名以省略号显示；行内操作控件仍可见且可点击。

- **Given** 同上窄视口  
  **When** 用户打开长文件名文件进入编辑器  
  **Then** 标题行不因文件名过长而产生横向滚动；文件名以省略号显示或等价处理；主要按钮行不被挤出视口。

### B. 编辑器信息架构（窄屏）

- **Given** 视口宽度不足以将“标题 + 按钮”舒适地放在同一行  
  **When** 用户进入编辑器  
  **Then** 标题独占一行；主要操作按钮独占一行；两行均左对齐（或遵循现有弹窗内容区统一左内边距）。

- **Given** Tab 文案 + 回滚控件总宽度超过一行  
  **When** 用户查看 Tab 与回滚区域  
  **Then** 允许折行为两行；整体左对齐；不出现为了单行显示而触发的横向滚动。

### C. 设置面板一致性

- **Given** 用户在扩展设置中查看 VFS 相关配置  
  **When** 与 VFS 弹窗并排对比（或先后打开）  
  **Then** VFS 相关控件在字色、背景层级、输入框与按钮边框风格上与弹窗一致；不出现因本扩展样式导致的明显“另一套皮肤”。

### D. 回归范围（非功能）

- **Given** 桌面常见宽度（例如 ≥1280px 弹窗可用宽度）  
  **When** 用户正常使用各 Tab  
  **Then** 不出现明显布局回退（例如不必要的过高空白、Tab 不可读）；若存在折行，应仍保持对齐与可读。

## 风险与待确认项

- **宿主皮肤差异**：SillyTavern 不同主题可能对设置面板注入全局样式；本需求以“本扩展可控 DOM 范围内一致”为目标，必要时在验收中记录主题差异为已知限制。
- **窄屏断点**：具体使用单一断点还是渐进式布局，由实现阶段 SPEC 选型；本 PRD 以 390/480 级别验收通过为准。
