# VFS Slideshow Style Polish 需求说明

## 背景

当前 VFS 的“幻灯片/阅读模式”界面在视觉与交互上与编辑器/预览顶部栏不一致：按钮样式不统一、控件分散且存在多余功能（目录切换 select、vertical 按钮）。这会降低使用时的整体一致性与可理解性。

## 目标

- 将“幻灯片/阅读模式”的入口命名与界面文案统一为 **“幻灯片”**。
- 将幻灯片界面的按钮样式与布局对齐 **编辑器/预览顶部栏**（Back + 右侧图标按钮的风格）。
- 移除多余控件，简化界面，只保留核心浏览能力（上一页/下一页）。

## 范围

### 包含范围

- 将 UI 文案 **“幻灯片/阅读模式” → “幻灯片”**（入口菜单/按钮/提示文案中出现处）。
- 幻灯片界面顶部栏改造：
  - **同一行**展示：返回按钮 + 上一页按钮 + 下一页按钮 + 当前文件名
  - 按钮风格对齐编辑器/预览顶部栏（`menu_button` + 图标按钮语义一致）
  - 当前文件名在同一行占剩余宽度，过长时省略号展示，并提供 `title` 完整提示
- 移除控件：
  - 移除目录切换 `select`（不再允许切换目录）
  - 移除 `vertical` 按钮

### 不包含范围

- 不新增自动播放、随机播放、页码跳转、复制内容等高级能力。
- 不调整幻灯片内容渲染（Markdown/HTML 渲染样式）本身，只做顶部栏与控件改造。
- 不改变文件列表、编辑器、阅读器等其它模式的交互逻辑。

## 功能需求

1. **入口命名**
   - 所有原“幻灯片/阅读模式”展示给用户的文案，改为“幻灯片”。

2. **顶部栏布局与交互**
   - 顶部栏按钮置于同一行，风格对齐编辑器/预览顶部栏。
   - 顶部栏包含：
     - 返回文件列表（Back）
     - 上一页（Prev）
     - 下一页（Next）
     - 当前文件名（可点击与否不做要求；默认仅展示）
   - 当前文件名：
     - 同行展示，过长省略号
     - `title` 显示完整文件名

3. **移除冗余控件**
   - 移除目录切换 `select`，目录固定为进入幻灯片时的目标目录（或保持现有默认目录策略，但不再提供 UI 切换）。
   - 移除 `vertical` 按钮与相关逻辑。

## 非功能需求

- **一致性**：按钮视觉（尺寸、圆角、边框、hover/active）与编辑器/预览顶部栏一致。
- **可用性**：键鼠/触控均可点击；按钮可访问性（`aria-label` / `title`）保持合理。
- **回归安全**：不影响 editor/reader/list 的现有行为；不引入滚动抖动问题。

## 验收标准

- AC1：入口处不再出现“幻灯片/阅读模式”，统一显示为“幻灯片”。
- AC2：进入幻灯片界面后，顶部栏为单行布局，按钮风格与编辑器/预览顶部栏一致。
- AC3：顶部栏不再出现目录切换 `select`。
- AC4：顶部栏不再出现 `vertical` 按钮。
- AC5：顶部栏显示当前文件名；文件名过长会省略，悬浮可看到完整 `title`。

## 风险与待确认项

- 目录切换移除后，若存在依赖该能力的使用场景，将无法在幻灯片内切换目录；需要用户确认这确实是预期（当前需求明确为“多余，移除”）。
