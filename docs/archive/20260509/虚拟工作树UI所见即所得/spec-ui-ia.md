# 虚拟工作树 UI 交互与信息架构需求说明

## 背景

本文件聚焦“用户看见什么、如何操作、页面如何流转”。在移动端对齐标准手机文件系统体验，在桌面端做增强布局，但两端功能集合保持一致。

## 目标

- 明确移动端与桌面端的页面结构和映射关系。
- 明确 7 个动作在文件/文件夹两类对象上的可见性与触发路径。
- 明确阅读页、编辑页、幻灯片模式的交互流转和行为边界。
- 为实现和测试提供可验证的 IA（信息架构）与交互基线。

## 范围

### 包含范围

- 入口后的多 Tab 弹窗信息架构（Tab1/Tab2/Tab3）。
- Tab1 文件管理器中的目录浏览、动作菜单、页面跳转。
- 文件阅读页与编辑页的 UI 行为定义。
- 文件夹幻灯片/阅读模式的 UI 行为定义。
- 移动端与桌面端的固定映射方案。

### 不包含范围

- 渲染引擎与后端算法细节。
- 存储、同步、接口协议字段定义。
- CI、打包、发布流程。

## 功能需求

1. **信息架构**
   - 弹窗包含 3 个 Tab：
     - Tab1：文件管理器
     - Tab2：提交记录
     - Tab3：日志
   - 默认打开 Tab1。

2. **文件管理器动作菜单（More）**
   - 统一动作集合：
     1. 切换状态
     2. 删除
     3. 查看（仅文件）
     4. 编辑（仅文件）
     5. 重命名
     6. 展示策略（仅文件夹）
     7. 幻灯片/阅读模式（仅文件夹）
   - 文件与文件夹按类型显示可用动作，非法动作不可见不可触发。

3. **页面流转**
   - 点击“查看”进入阅读页（只读）。
   - 点击“编辑”进入编辑页（可编辑 markdown 源码）。
   - 编辑页顶部 More 可切换预览模式。
   - 点击“幻灯片/阅读模式”进入文件夹阅读模式。

4. **阅读页**
   - 不提供编辑能力。
   - markdown/html 以渲染结果展示。
   - 阅读页与预览页的渲染视觉规则保持一致。

5. **编辑页**
   - 默认源码编辑视图。
   - 支持预览模式切换。
   - 支持查看编辑历史与手动回滚入口。
   - 离开编辑页前若存在未保存改动，先弹出确认提示；用户选择强制退出时不保存。

6. **文件夹幻灯片/阅读模式**
   - 支持目录切换。
   - 支持左右翻页。
   - 支持切换为上下滑动模式。

7. **跨端映射**
   - 移动端：单列、页面跳转式。
   - 桌面端：增强布局（可多栏同屏），但功能不减少。
   - 关键动作命名、顺序、反馈语义一致。

8. **日志刷新交互**
   - Tab3 默认手动刷新。
   - 当发生“消息编辑”或“收到消息”事件时，自动触发一次日志刷新。
   - 若事件发生时 Tab3 未激活，可延迟到 Tab3 首次激活时执行一次刷新（且仅执行一次），仍视为满足自动刷新要求。

## 非功能需求

- **一致性**：移动端与桌面端在功能语义上一致。
- **可学性**：动作命名与入口位置稳定，降低学习成本。
- **可访问性**：移动端触控区域清晰，桌面端键鼠操作高效。

## 验收标准

1. 弹窗中 Tab1/Tab2/Tab3 的信息架构与默认 Tab 行为符合定义。
2. 文件/文件夹动作菜单按对象类型严格限制。
3. 查看、编辑、幻灯片三条主路径可完整流转且返回路径明确。
4. 编辑页可在源码与预览间切换，不丢失当前编辑上下文。
5. 幻灯片模式支持目录切换、左右翻页、上下滑动三种能力。
6. 桌面端在不减少能力前提下提供增强布局。

## 风险与待确认项

- 移动端与桌面端在同屏布局下的状态同步细节（如选中项高亮规则）需实现阶段细化。
- 幻灯片模式中的“目录切换 + 翻页”优先级冲突需定义手势与按钮行为。

## 已确认决策（2026-05-08）
