# toolbar-button-unification 需求说明

## 背景

当前文件管理区域顶部控件（文件管理器标签、Up、更多操作）存在以下问题：

- 文案与按钮样式混用，视觉不统一。
- 文本按钮占用空间较大，影响紧凑度。
- 顶部控件缺少明确分组，导航与动作语义不清晰。

## 目标

- 将文件管理面板头部控件统一为**图标化按钮**（使用 `title/aria-label` 承载语义）。
- 采用**分组布局**：左侧导航组、右侧动作组。
- 在保证紧凑的同时维持视觉一致（尺寸、间距、对齐、边框风格统一）。
- 与 tab 区域做差异化：tab 保持文本导航语义，避免与面板头部图标重复。

## 范围

### 包含范围

- 组件范围：文件管理区域头部（`VfsFileManagerPanel` + `VfsActionMenu` 的 toggle 入口）
- 覆盖元素：
  - 文件管理器标签（由文本标签改为图标化标识，或紧凑图标按钮）
  - Up 按钮（图标化）
  - 更多操作按钮（图标化 toggle）

### 不包含范围

- 不调整“新建目录/新建文件”菜单项（它们属于下拉内容项，不在本次顶部按钮组范围）。
- 不要求将 tab（文件管理/提交记录/日志）全图标化。

## 功能需求

### FR-1 面板头部图标化

- 文件管理面板头部的目标控件使用图标表达：
  - 文件管理标签（建议 folder/list 语义图标）
  - 返回上级（Up）
  - 更多操作（ellipsis/slider 等语义图标）
- 每个图标按钮必须具备：
  - `title`（中文提示）
  - `aria-label`（无障碍语义）

### FR-2 分组布局

- 头部布局分为两组：
  - 左组：文件管理标识 + Up（导航属性）
  - 右组：更多操作（动作属性）
- 保持一行布局，间距统一、对齐一致。

### FR-3 Tab 与面板差异化

- 虚拟文件系统（多 tab）保留文本 tab（如“文件管理 / 提交记录 / 日志”）作为主导航。
- 模板管理（单 tab）不渲染 tab 头部，直接显示内容区。
- 面板头部保留图标化导航/操作控件，不与 tab 再做同语义重复强化。

### FR-4 紧凑与一致

- 按钮尺寸统一（建议与 ST `mes_button/menu_button` 视觉接近）。
- 图标垂直对齐一致，避免“一个顶边一个居中”的错位。
- 背景、边框、圆角、文字提示风格与当前弹窗主题一致。

## 非功能需求

- **可访问性**：图标按钮必须具备可读提示与键盘可聚焦能力。
- **主题兼容**：优先复用 ST 变量与 class，减少硬编码色值。
- **可维护性**：图标映射与提示文案集中管理，避免散落在模板中。

## 验收标准

- **AC-1 头部图标化**：面板头部的“文件管理标识 / Up / 更多操作”以图标呈现，hover 可见中文 `title`。
- **AC-2 分组明确**：左导航组与右动作组视觉上清晰分离。
- **AC-3 导航差异化**：多 tab 场景显示文本 tab；单 tab（模板管理）隐藏 tab 头部。
- **AC-4 视觉统一**：按钮尺寸、间距、边框、图标对齐一致，无突兀控件。
- **AC-5 紧凑性**：头部整体宽度收缩，不挤压路径/列表可用空间。

## 风险与待确认项

- 图标语义可能存在歧义（尤其“文件管理器标签”）；需通过 `title` 明确中文解释。
